7. State machine ARP/Ethernet/ICMP/IP/TCP/routing — ✅ terkonfirmasi
Engine menyimpan 1.404 kode langkah *_FC_* (flow-chart), masing-masing berpasangan dengan kunci terjemahan. Ini enumerasi eksplisit tiap state machine. Contoh terkonfirmasi:
Protokol	Jumlah langkah	Contoh langkah
CROUTINGPROCESS_FC_	39	LOOKUP_TABLE_IN, USE_DEFAULT_GATEWAY, DECREMENT_TTL_PS, SEND_TTL_EXPIRED, CEF_LOOKUP_ENTRY
CMACSWITCHER_FC_	42	ADD_NEW_MAC_ADD, DST_NOT_IN_TABLE, BROADCAST_TO_ALL_TRUNK, DROP_PORT_BLOCKED
CARPPROCESS_FC_	38	CONSTRUCT_REQUEST, ADD_TO_TABLE, PROXY_ARP_ENABLED, GRATUITOUS_FIX
CTcpConnection_FC_	46	RECEIVE_SEGMENT, RETRANSMIT, SEND_TCP_WINDOW, BUFFER_DATA_NAGLE_ALG
CHOSTIP_FC_	31	SET_NEXT_HOP, SET_TTL, DEFAULT_GATEWAY_NOT_SET, MATCH_IP_MULTICAST
CICMPPROCESS_FC_	14	ICMP_ECHO_REPLY, ICMP_TTL_EXCEEDED, ICMP_PORT_UNREACHABLE
CIPFRAGMENTATIONPROCESS_FC_	12	TOTAL_LENGTH_GREATER_THAN_IP_MTU, STORE_FRAGMENT, SUCCESSFUL_REASSEMBLING
Sufiks _PS = Process Send, _PR = Process Receive. Ada juga Ethernet (CETHERNETENCAPPROCESS_FC_DECAP/ENCAP/MAC_MATCH) dan QoS (CWFQ_FC_QOS_WFQ_*, CCBWFQ_*) — membuktikan cakupan stack lengkap.
8. Capture / Forward — ⚠️ sebagian terkonfirmasi, sebagian inferensi kuat
Terkonfirmasi (nama slot & tombol nyata):

9. Bagaimana router memutuskan — ✅ terkonfirmasi
Fungsi mesinnya: Routing::CRoutingProcess::vftable[5] = FUN_14094c530 (26.901 byte) — decompile menunjukkan operasi nyata: lookup RIB ("), routed via RIB"), "), unroutable", "\nICMP: time exceeded (time to live) send to", "\nICMP: unreachable host icmp message sent to", "\nICMP: dst ( ... protocol unreachable sent to", ", encapsulation failed", ", rcvd local pkt", ", g=" (gateway goto), IP: tableid=0 (VRF), interface VirtualPortGroup0, 819HG-4G-IOX, helper address.
Urutan langkah dari enumerasi CROUTINGPROCESS_FC_*:
CEK PORT IP (CHECK_PORT_IP_PR)          → apakah paket ke IP milik saya?
  └─ CHECK_MULTICAST_BROADCAST / BROADCAST_MULTICAST_CHECK_PR
       └─ HIGHERPROCESS_NOTSET_PR       → drop: "If no source process is set, drop the frame."
CHECK_TTL_ZERO / INVALID_TTL → SEND_TTL_EXPIRED   → ICMP Time Exceeded
LOOKUP_TABLE_IN → LOOKUP_TABLE_OUT                → "looks up the destination IP address in the routing table"
  ├─ MATCHING_ENTRY_PS → CONNECTEDROUTE_SET_PORT_PS / STATIC_ROUTE_SET_PORT_PS
  │                     → NOTSTATIC_NOTCONNECTED_PS
  └─ NO_MATCHING_ENTRY_PS → USE_DEFAULT_GATEWAY   → "sends the packet to the default-gateway"
CEF_LOOKUP_ENTRY → CEF_FOUND_ENTRY / CEF_NO_ENTRY → CEF_DISPATCH
  └─ NO_OUT_PORT / NULLPORT_PS / NO_VALID_SOURCEIP  → drop
DECREMENT_TTL_PS                                  → "decrements the TTL on the packet"
ENCAP_TO_PACKET → (gagal) "encapsulation failed"
RECEIVE_LOCAL_PACKET                              → paket untuk diri sendiri
DROP_OUT_NON_ICMP_BROADCAST
ICMP_HOST_UNREACHABLE / PROTOCOL_UNREACHABLE / ADMIN_PROHIBITED_UNREACHABLE
FORWARD_HELPER / HELPER_REPLY                     → ip helper-address
ASA: OWN_PORT_DROP, NO_FORWARD, NO_NAMEIF, SSH/TELNET_NOT_CONFIGURED
Lalu resolusi L2 via ARP: CARPPROCESS_FC_CHECK_ROUTING_TABLE → CARPLOOKUP_FC_UNICAST/BROADCAST/MULTICAST → NOT_FOUND_BUFFER (paket dibuffer) / NOT_FOUND_DROP / FOUND / FOUND_ADJACENCY.
