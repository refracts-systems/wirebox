03 / FFI, lock, dan ownership

beginner — Session Rust memiliki handle opaque; buffer yang dikembalikan adalah salinan. Pengguna wrapper tidak menerima pointer ke array internal Zig.

intermediate — PhantomData<Rc<()>> menjadikan Session !Send/!Sync. api_lock adalah mutex global untuk seluruh registry. close mengambil Option handle; Drop memanggil cleanup tanpa destroy dua kali.

advanced — SAFETY comment harus menjelaskan alignment, writable capacity, lifetime, lock dan ownership. Poisoned lock direcover; itu tidak memperbaiki korupsi native. C caller tetap wajib memenuhi kontrak pointer dan serialisasi.

overview — Lihat Session::new → submit_probe → read_probe → close_inner. Input dipinjam selama call sinkron dan disalin oleh Zig.

standard — read_probe mengalokasikan record initialized, memeriksa count ≤ capacity dan length ≤ payload limit sebelum membentuk Vec. Kesalahan ABI menjadi Error, bukan pointer yang tetap dipakai.

deep-dive — Mutex per call tidak berarti workflow beberapa call atomik. Jalur network yang gagal setelah event di-pop punya state failed; jangan mengasumsikan rollback seluruh run seperti database transaction.

Mental model: Handle seperti connection ID dengan generation; Drop mirip RAII connection cleanup, bukan garbage collection Zig.
Perhatikan: Borrow checker Rust tidak mengetahui lifetime memori native. Jangan menyimpan pointer Zig di UI.

04 / Handle namespace dan ABA

beginner — Handle terdiri dari index slot dan generation. Generation membedakan pemilik lama dan baru pada index yang sama.

intermediate — Bit 63..62 adalah namespace, index 31..0, generation 61..32. Probe namespace 00, runtime 10, network 11. Maksimum generation adalah 2^30−1; nol retired.

advanced — Destroy pada max harus retire, bukan wrap. Dua assignment Kandidat A membakar generation dan menghasilkan handle namespace asing. Ditolak lookup setelah create sukses adalah pelanggaran kontrak, meski tidak menyebabkan crash.

overview — lookup menolak namespace salah sebelum mencari slot. wb_create melewati context aktif atau generation nol.

standard — wb_destroy menghapus context dan increment satu kali; pada max menjadi nol. Uji boundary menyuntik state internal agar tidak perlu satu miliar call.

deep-dive — Argumen no-ABA: generation reusable meningkat monotonik dan tidak berulang; index tetap tidak cukup untuk mengidentifikasi pemilik. Property sampling mendukung, tetapi tidak menggantikan argumen domain seluruh lifecycle. State yang sengaja dikorupsi di luar domain bukan jaminan memory safety.

Mental model: Seperti optimistic-lock version pada row: ID sama belum berarti versi entity sama.
Perhatikan: Check bit63 redundan jika handle >> 62 sudah diperiksa. Jangan mengubah retirement menjadi +%=.
kernel/src/abi.zig:44 · excerpt source aktual
fn lookup(handle: u64) ?*Slot {
    // Top two bits identify probe/counter/network registries.
    if (handle >> 62 != 0) return null;
    const index: u32 = @truncate(handle);
    const generation: u32 = @intCast(handle >> 32);
    if (index == 0 or index > session_limit or generation == 0) return null;
    const slot = &slots[index - 1];
    if (slot.generation != generation or slot.context == null) return null;
    return slot;
}

05 / Scheduler waktu virtual

beginner — Waktu virtual adalah angka nanosecond dalam engine. Event diurutkan berdasarkan time_ns lalu ID; engine tidak menunggu wall clock.

intermediate — Binary heap menyimpan event berikutnya; timer registry mendukung cancel. ID baru menaik memastikan urutan same-time stabil. Budget membatasi kerja dalam satu runUntil.

advanced — Counter step memeriksa overflow dan menyalin RNG sebelum commit. Domain beginDomain sengaja commit metadata sebelum dispatcher; failure contract berbeda. Perlu test interleaved cancel untuk menjaga heap setelah delete arbitrer.

overview — runUntil memproses hanya event yang jatuh tempo sampai horizon dan budget. Step kosong tidak memajukan clock.

standard — Budget nol tidak menjalankan event due dan menghasilkan reason budget. Horizon kosong dapat memajukan waktu. Timer periodik perlu budget agar drain tidak berjalan selamanya.

deep-dive — Test hardening membandingkan schedule/cancel/step melawan model linear selama 5×4.000 operasi. Model linear memilih minimum tanpa memakai less() atau pop() produksi; oracle yang berbeda mengurangi common-mode bug.

Mental model: Seperti priority job queue dengan logical clock dan deterministic sequence key.
Perhatikan: Queue event ≠ log GUI. Memangkas log tidak boleh membatalkan event yang masih pending.

06 / Jurnal, cursor, dan retensi

intermediate — Ordinal menjadi cursor read. Ring buffer menyimpan suffix terbaru; dropped memberi tahu riwayat terpangkas. Retention nol tetap menghitung event dan menjalankan state.

advanced — Ini observability journal, belum event-sourcing lengkap. Replay state aktif memerlukan queue, cache, timer dan RNG; trace saja tidak menyediakan checkpoint.

overview — Baca append dan read, lalu bandingkan snapshot dengan retention 0/1/7/256 pada runtime_tests.zig.

standard — Consumer mengirim after_ordinal, kemudian membaca batch berikut. Jika retention terlewati, dropped dan ordinal menjelaskan gap. Jangan menggunakan row count sebagai jumlah callback scheduler.

07 / Byte parser dan protocol view

beginner — Byte wire punya urutan eksplisit. Struct native punya padding/alignment sehingga tidak boleh dipakai langsung sebagai header jaringan.

intermediate — ipv4 memeriksa panjang minimum, IHL, total length dan checksum sebelum slicing payload. view memetakan field ke offset byte/bit, sehingga inspector bisa memilih byte yang benar.

advanced — Unsupported options/fragment/protocol dibedakan dari malformed. Checksum valid belum berarti seluruh semantic packet benar. Mutation corpus harus memiliki kontrol valid agar tidak sekadar menguji early rejection.

overview — Ikuti bytes → ipv4 → icmp → view. Gunakan golden header beku dan checksum Rust independen sebagai oracle.

standard — decrement menurunkan TTL dan menghitung ulang checksum IP, bukan ICMP. Padding Ethernet bukan bagian total length IPv4. Field besar menyimpan rentang dengan value sentinel, bukan semua payload di u64.

deep-dive — 4.000 input hardening memadukan valid packet, bit flip, truncate dan random length hingga 1600; setiap successful view harus berada di dalam input. Ini bounded mutation testing, bukan bukti conformance seluruh RFC atau fuzzing jangka panjang.

Mental model: Seperti parsing message untrusted dengan schema dan bounds sebelum deserialize nested object.
Perhatikan: Jangan menutupi unsupported sebagai sukses. Decoder dan UI field map harus memakai byte aktual.

pub fn ipv4(bytes: []const u8) Error!Ip {
    if (bytes.len < 20) return error.TruncatedIpv4;
    if (bytes[0] >> 4 != 4 or bytes[0] & 15 < 5) return error.InvalidIpv4;
    const header = @as(usize, bytes[0] & 15) * 4;
    if (bytes.len < header) return error.TruncatedIpv4;
    const total: usize = @intCast(read(bytes[2..4]));
    if (total < header) return error.InvalidIpv4;
    if (total > bytes.len) return error.TruncatedIpv4;
    if (checksum(bytes[0..header]) != 0) return error.InvalidIpv4Checksum;
    if (header != 20) return error.UnsupportedOptions;

09 / Ping dari command sampai byte reply

beginner — Ping membuat ICMP echo, header IPv4 dan route lookup. Jika MAC next-hop belum diketahui, ARP berjalan lebih dulu.

intermediate — resolve mengecek ARP cache, membuffer versi IP dan menjadwalkan retry. transmit menghitung antrean egress, serialization delay dan propagation; arrival di-dispatch scheduler.

advanced — Versi paket immutable melacak parent/cause. Switch flooding berbagi versi byte dengan transmission ID berbeda. Router membuat versi baru untuk TTL/checksum dan mengganti L2 di hop berikutnya.

overview — Alur: Rust Network::ping → C ABI wb_net_ping → Zig ping → sendIp → resolve → transmit → beginDomain → receive → reply.

standard — Trace mencatat event/version/transmission; packet_id tidak sama dengan version_id atau event_id. Byte disalin ke Rust agar inspector aman setelah call berikutnya.

deep-dive — ICMP error suppression mencegah error-of-error/broadcast. Failed resource state tidak boleh dilaporkan sebagai sukses. S01–S05 dan 37 kasus negatif menguji subset; belum TCP, VLAN, hardware/vendor fidelity atau seluruh fitur PT.

Mental model: Seperti command handler yang menghasilkan pekerjaan tertunda dan read model dengan causal IDs.
Perhatikan: Satu successful ping bukan bukti seluruh routing vendor setara; UI saat ini masih probe.

18. Apakah beginDomain gagal dispatcher berarti rollback seluruh event?

Jawaban: Tidak; metadata sudah commit dan world menjadi failed. Counter step memeriksa overflow dan menyalin RNG sebelum commit. Domain beginDomain sengaja commit metadata sebelum dispatcher; failure contract berbeda. Perlu test interleaved cancel untuk menjaga heap setelah delete arbitrer. Test hardening membandingkan schedule/cancel/step melawan model linear selama 5×4.000 operasi. Model linear memilih minimum tanpa memakai less() atau pop() produksi; oracle yang berbeda mengurangi common-mode bug. Sumber: kernel/src/runtime.zig.
